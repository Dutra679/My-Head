# My Head

Página pessoal desenvolvida para praticar HTML, CSS, JavaScript e um fluxo de trabalho baseado em GitFlow.

## Acessar o projeto

[Visualizar no GitHub Pages](https://dutra679.github.io/My-Head/)

## Funcionalidades

- Layout responsivo para computadores, tablets e celulares
- Navegação entre as seções da página
- Animação com controle de pausa
- Menu adaptado para telas menores
- Efeitos de entrada durante a rolagem
- Estrutura semântica e recursos de acessibilidade

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Estrutura do projeto

```text
My-Head/
├── .github/
│   └── PULL_REQUEST_TEMPLATE.md
├── css/
│   └── style.css
├── img/
│   └── cabeca.jpg
├── js/
│   └── main.js
└── index.html
```

## Fluxo de desenvolvimento

O projeto utiliza as branches `main`, `develop` e `feature/*`. As funcionalidades são desenvolvidas em uma feature branch, revisadas em um Pull Request para `develop` e depois integradas à `main` para publicação.
